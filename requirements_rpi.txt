# GlaDOS — Raspberry Pi / NLP-only mode requirements
#

# Uses NLP mode (nlp_mode: true) for intent classification + direct tool execution.

# Install: pip install -r requirements_rpi.txt
# Run:     python main.py   (with nlp_mode: true in glados_config.yml)
